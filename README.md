# 只想认真读书的我，为什么打个乒乓球也能触发恋爱事件？

桂森力工学院的轻松校园恋爱视觉小说。电脑与手机浏览器均可游玩，单次正常阅读约 20 分钟，三个可重玩的告白结局。

当前版本使用粉色、蕾丝边与蝴蝶结界面。雨姐和噶辉告白成功后展示拥抱 CG 和爱心动效；Judy 按用户选择使用双人同框与动态爱心过渡画面。已收集的画面可在回忆相册重看。

乒乓球小游戏有两个入口：标题页「球馆练习」，以及第五章比赛前的「赛前热身」。看准时机条的粉色区域，按空格或点击击球，共十球，提供慢速辅助、重试和跳过；成绩不限制告白对象。新增功能不改变旧剧情条目编号，保留旧存档兼容。

## 游玩

从 GitHub 下载项目后，打开本地版即可游玩。仓库默认设为私有。

本地版：打开 dist/index.html 即可。或者在此目录运行 `node server.mjs`，浏览器访问 http://localhost:4173 。无须安装依赖。

电脑点击对话框或按空格、回车继续；手机点击对话框。文字未显示完时，点击可立即显示整句。选择出现后，点击选项继续。

支持六个手动存档、一个自动存档、继续上次故事、历史回顾、自动播放、已读快进、文字速度、文字大小、音乐及音效音量设置。进度与回忆相册保存在当前浏览器，设备与站点地址之间不自动同步。

音乐与音效在首次交互后播放，可在设置中静音。无角色配音。

## 文件

- dist/index.html：游戏入口。
- dist/story.js：完整剧情与角色配置。
- dist/game.js：视觉小说引擎与存档、声音、结局逻辑。
- dist/style.css：桌面和手机界面。
- dist/assets/：已接入的游戏美术素材。
- validate.mjs：剧情结构、分支回扣、结局与资源完整性检查。
- 素材来源与生成提示词.md：来源与生成记录。

检查命令：`node --check dist/game.js`、`node --check dist/story.js`、`node validate.mjs`。

时长为阅读体验目标，不设置强制等待。共通剧情加一段告白尾声约 6300 字，实际时间受阅读和操作速度影响。
